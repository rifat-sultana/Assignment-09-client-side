**Project Name**: "Tutor Point"


## Features

- Browse available tutors with detailed profiles and professional images.
- Search tutors by subject and location.
- Responsive and modern UI design for mobile, tablet, and desktop.
- View tutor details including subject, hourly fee, and location.
- Secure and fast performance using Next.js, MongoDB and authentication by      better-auth.


##  Technologies Used

- Next.js
- React
- Tailwind CSS
- MongoDB
- Express.js
- Node.js
